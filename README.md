# motor-grafico-fpga
Coprocessador gráfico programável em Verilog para FPGA (DE1-SoC), inspirado em consoles de 16 bits. Possui ISA de 32 bits, busca de instruções, unidade de controle, ULA, banco de registradores e datapath, integrando motores de background, sprites e polígonos ao compositor e ao controlador VGA. Projeto da disciplina MI - Sistemas Digitais, UEFS.
